# Darwin Baisa

Singapore. Java, distributed systems, and AI tooling.

## Projects

- **[quackjvm](https://github.com/bdarwin/quackjvm)** - DuckDB for the JVM: Java objects stored as
  typed columns and queried with SQL, plus a DuckDB-backed persistence plugin for CQEngine.
  On Maven Central as `io.github.bdarwin:quackjvm-core`.
  [Documentation](https://bdarwin.github.io/quackjvm/).
- **[cairn](https://github.com/bdarwin/cairn)** - an S3-compatible object server in Java. Just started.
- **[xml-grid-view](https://github.com/bdarwin/xml-grid-view)** - a read-only XML tree and grid viewer
  with search and XPath, for VS Code and IntelliJ.
- **[intellij-classic-ui-remote](https://github.com/bdarwin/intellij-classic-ui-remote)** - the Classic
  (pre-New-UI) look for IntelliJ IDEA 2026.2, including remote development sessions.
- **[tokenmiser](https://github.com/bdarwin/tokenmiser)** - a plugin for GitHub Copilot CLI and Claude
  Code that trims noisy tool output to cut token use.
- **[sectop](https://github.com/bdarwin/sectop)** - a macOS menu bar app showing which apps have access
  to what, with a switch to turn it off.

## Small runnable examples

Each runs offline, with no API key:

- [spring-ai-tour](https://github.com/bdarwin/spring-ai-tour) - six Spring AI capabilities in one Spring Boot app.
- [a2a-protocol-example](https://github.com/bdarwin/a2a-protocol-example) - the Agent2Agent protocol, server and client in one file.
- [llm-eval-example](https://github.com/bdarwin/llm-eval-example) - a minimal evaluation of an LLM system.
- [multi-agent-support-triage](https://github.com/bdarwin/multi-agent-support-triage) - specialist agents triaging tickets under enforced tool permissions.
